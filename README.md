覆盖城市服装、家纺、家具、建筑和交通相关的纺织品、纤维，以及可用于制纤的聚合物及前驱材料。PET、芳纶等材料的树脂、薄膜或块材也可纳入，但必须有同一配方、形态与处理状态的 TG–LOI 原文证据。

每行是一条 TG 测试记录。同一样品的不同气氛或升温速率保留多行，不能重复计为独立样品。空白表示没有可采用的原文数据；零值仍是零。T5、T10、Tonset 与 Tmax 各按原文定义保留，残余质量同时标明对应温度。

CSV 是正式主表的阅读版；用于研究时请保留同一行的测试条件与来源，不把不同形态、洗涤或老化状态的数据混合。未核验候选、冲突及范围待审记录不进入阅读表。

采集使用本地只读 MetaData 文献库中的 CSV 索引、PDF／HTML 和补充材料，以原生文本读取并按文献并行审核。不联网采集文献，不读取 PDF 页面图像；公开仓库不存放全文、私人批注或本地文件路径。

需要查完整字段或审核过程时，请查看 [完整主表](data/tg_loi_textile_master.csv)、[当前进度](SOURCE_VERIFICATION_PROGRESS.md) 或 [维护说明](docs/MAINTENANCE.md)。日常查看数据只需打开上面的 CSV 表。
